## Individual Contributions

### Carina Cocora
Carina was responsible for the **back-end development** of Lock.Pic. She implemented the server-side functionality using **Google Firebase**, including the setup of **Firestore** for structured data and **Firebase Storage** for handling image uploads.  

She developed core use cases (e.g., `RegisterUser` and `GetUserData`), which were used by the front-end to manage user sessions and data retrieval.  

She also implemented the project's **authentication and security architecture**:  
- Used **Firebase Authentication** with OAuth 2.0 tokens for secure user verification.  
- Built a **Cloud Run function** to handle token retrieval, authorizing client access to Firebase services.  
- Configured **Firestore Security Rules** to enforce access controls.  

Additionally, she collaborated closely with the front-end team to ensure seamless integration between system components.
